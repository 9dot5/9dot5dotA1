# Diagrams

**Review by:** 2027-01-25

**Owner:** Rui Silva (`9dot5`) · **Status:** Proposed

Diagrams are versioned as source (Mermaid or Draw.io XML) next to any exported image, so
every change to a diagram is reviewable.

| Folder | Shows |
|---|---|
| `context/` | Who and what interacts with the platform (see `context/system-context.md`) |
| `architecture/` | Components, interfaces, data flows, trust boundaries |
| `security/` | Trust boundaries and threat-model views |
| `operations/` | Deployment, backup and recovery flows |

Each diagram carries a legend and a date. A diagram that disagrees with its document is a defect.
