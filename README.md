Platform for knowledge, governance, security, AI and automation, built incrementally
and driven by return on investment. Infrastructure is an enabler, not the goal.

## Status

**Phase 00 — Governance foundation.** No infrastructure code exists in this repository
by design. The first deliverable is the set of decisions, principles and processes that
every later phase must respect.

## Source of truth

- **GitHub** — engineering truth: code, ADRs, diagrams, automation.
- **Confluence** — organisational truth: policies, runbooks, roadmaps. Mirrors this repo's `governance/` and `security/` when published.
- **Jira** — execution: Epic → Story → Task, each linked to an ADR or phase document.

When two sources disagree, the Git-tracked document wins and the other source is corrected.
