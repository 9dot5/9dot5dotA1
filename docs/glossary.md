# Glossary

**Owner:** Rui Silva (`9dot5`) · **Status:** Proposed · **Review by:** 2027-01-25

| Term | Definition |
|---|---|
| **ADR** | Architecture Decision Record. A recorded decision with context, options and consequences. |
| **Agent** | An AI system that takes actions on the platform under a scoped identity (see AGENT_STRATEGY). |
| **Baseline** | The minimum set of security controls every component must meet (SECURITY_BASELINE). |
| **Control** | A measure that reduces a risk. Referenced to ISO/IEC 27001 Annex A where applicable. |
| **Canonical store** | The single authoritative location for a kind of fact (see ADR-0008). |
| **CODEOWNERS** | File that assigns required reviewers to paths in the repository. |
| **Component** | A deployable or consumable part of the platform. |
| **Deprecated** | ADR status: no longer recommended, kept for history. |
| **Epic / Story / Task** | Jira levels of execution, in that order. |
| **Gate** | A phase exit point that requires the owner's sign-off. |
| **HITL** | Human in the loop: a named human approves consequential actions. |
| **MCP** | Model Context Protocol. A standard for exposing tools and data to AI clients. |
| **Owner** | The person with final decision rights for the platform (PROJECT_CHARTER). |
| **Phase** | A roadmap stage with objectives, deliverables and a gate. |
| **Proposed / Accepted / Superseded** | ADR statuses. See adr/ADR_TEMPLATE.md for the full lifecycle. |
| **RPO / RTO** | Recovery point objective (data loss accepted) and recovery time objective (time to restore). |
| **Risk** | A potential event with likelihood and impact, recorded with a treatment. |
| **RAG** | Retrieval-augmented generation: an AI system that answers from retrieved documents. |
| **Runbook** | Step-by-step operational procedure for a known task or failure. |
| **Service** | A running instance of a component on a host. |
| **Trust boundary** | A point where data or control crosses between parties of different trust. |
| **Zero trust** | Security model that does not trust network location; every request is verified (NIST SP 800-207). |
