# Phase 01 — Knowledge

**Owner:** Rui Silva (`9dot5`) · **Review by:** 2027-01-25

**Status:** Proposed · **Duration:** 3 weeks after Phase 00 · **Related:** ADR-0008

## Objective

Make the canonical knowledge store operational: GitHub as engineering truth, Confluence as
organisational truth (published from Git), Jira for execution, and a Rovo-style assistant
over published content once Phase 05 supplies retrieval.

## Deliverables

- [ ] GitHub organisation and repository created; branch protection on `main`
- [ ] Document template with metadata (owner, status, review date)
- [ ] Confluence space created; publication method decided and recorded in ADR (to be written)
- [ ] Jira project with Epic → Story → Task workflow linked to ADRs
- [ ] Glossary and naming conventions in use

## Exit criteria

- Each governance document has an owner and review date.
- One Confluence page published from Git, with the link recorded.
- At least one Jira epic traces to an ADR.

## Dependencies

Phase 00 accepted.
