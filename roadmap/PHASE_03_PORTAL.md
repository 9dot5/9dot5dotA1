# Phase 03 — Management Portal

**Owner:** Rui Silva (`9dot5`) · **Review by:** 2027-01-25

**Status:** Proposed · **Duration:** 4 weeks · **Related:** ADR-0009, DOMAIN_MODEL.md

## Objective

Define the portal that becomes the platform's first product: a single web entry point for
dashboards, knowledge, operations and AI, usable from browsers on desktop and mobile without
depending on the operating system.

## Deliverables

- [ ] Requirements derived from the Domain Model (Document, Service, Risk, Change)
- [ ] Navigation and information architecture
- [ ] Low-fidelity mockups for the three primary views: overview, knowledge, operations
- [ ] Health and resource signals from ADR-0009 displayed for each service
- [ ] Accessibility target agreed (WCAG 2.2 AA)
- [ ] ADR accepted for portal architecture and hosting

## Exit criteria

- Mockups reviewed against the security review triggers (the portal is an external interface).
- ADR accepted naming the hosting location.

## Notes

The portal's hosting host is chosen by capacity measurements, not preference (ADR-0007
applies by analogy to any resource-heavy component).
